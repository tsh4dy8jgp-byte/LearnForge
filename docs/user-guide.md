# Learner guide

## Learn and navigate

Open **Learning library**, choose a subject, and work through its lessons. A course provides four views:

- **Lessons:** teaching blocks, examples, callouts and saved reading completion.
- **Content map:** objectives and prerequisite relationships.
- **Practice & exams:** session configuration.
- **References:** author-provided source links and license.

Lesson completion is a reading record, separate from assessment performance. A newly published version starts its own completion and assessment evidence; older attempts remain in history.

## Choose a session

Select a short or full blueprint defined by the author.

**Mock mode** is timed and releases answers after submission. Leaving the page or changing your device clock does not pause the server deadline.

**Learning mode** is untimed. **Check answer** releases feedback and locks the response for that session. It supports balanced practice, previous mistakes, or weak-objective practice. Focused practice needs earlier completed evidence, may be shorter than the blueprint, and currently selects standalone questions. Use balanced blueprints for case studies.

One active session is allowed per account/course. Resume it through **Attempts & results**.

## Answer and save

| Format | Interaction |
| --- | --- |
| Single choice | Select one option |
| Select multiple | Select the requested number; uncheck an item to replace it |
| Matching | Drag a token, or select it and activate the target using click/keyboard |
| Dropdown | Choose an option for every blank |
| Sequence | Drag or use move buttons, then save the order |

Matching states whether tokens may be reused. With reuse disabled, placing a token elsewhere moves its assignment.

Changes save to the server. Wait for **All responses saved** before leaving. On failure, a pending response is stored on this device with **Retry saving** and **Use server answer** choices. Retries reuse the same request ID.

This recovery mechanism is not offline exam support. The server deadline still applies. When another tab caused a revision conflict, reload and decide which response to keep. Avoid editing one session in several tabs.

## Sections and submission

Some mock exams use locked case sections. **Finish this section** asks for confirmation, then prevents returning to it. The server rejects writes to previous and future sections. Learning mode permits normal navigation.

Submit when finished. Unanswered questions receive zero points. Expired mocks are finalized using the last server-saved responses and remain reviewable, but do not qualify for readiness.

## Understand your results

- **Fully correct** counts questions with every required part correct.
- **Points score** includes weighted partial credit when enabled.
- **Fresh questions** measures families not seen in any earlier session for your account/course.

Expand each result for your answer, the expected answer and explanation. Your session retains its original content version and grading policy.

## Use the dashboard

The overview shows lesson progress, sessions, objective evidence and suggested lessons. Objective percentages use fully correct answers from completed mocks; sample counts help you judge how much evidence exists.

Suggestions prioritize objectives with no independent evidence or weaker results. These are deterministic study suggestions, not a calibrated mastery model.

By default, the latest five short mocks OR latest three full mocks must each exceed 90%, also satisfying time and freshness requirements. See [assessment](assessment.md). Learning sessions contribute review evidence but never the readiness streak.

## Account and privacy

Account settings support password changes, a JSON history export and permanent account deletion after password confirmation. Sign out on shared devices. Drafts use browser local storage, scoped to your account; a shared browser profile is not a privacy boundary.

Exports contain your responses and released feedback. Account deletion removes live learning records; backup retention is the operator's responsibility.
