# Security policy

Please do not publish a suspected vulnerability in a public issue. Contact the project maintainers privately with a reproduction, affected version, and impact. Do not include learner data or credentials in a report.

LearnForge keeps answer keys server-side during active attempts, uses antiforgery protection for unsafe API requests, and treats content sources and learner responses as untrusted input. Deployments must follow `docs/security.md` and `docs/operations.md`.
